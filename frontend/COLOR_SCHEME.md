# 项目色彩规范

> 本文件定义项目全局色彩方案。所有页面开发/修改时 **必须** 遵循此规范。
> 禁止使用 antd-mobile 默认蓝色 `#1677ff` 作为主色调。

## 主色：酒红系

整体风格：低饱和度、沉稳高级的酒红/玫瑰灰色系。

| 角色 | 色值 | 说明 |
|------|------|------|
| **主色 (Primary)** | `#8B3A42` | 深酒红，用于按钮、链接、选中态、日历高亮、进度条等 |
| **辅助色 (Accent)** | `#C4737A` | 玫瑰灰，用于标签文字、次要链接等 |
| **标签背景 (Tag BG)** | `#F5E6E8` | 浅粉底，用于标签/徽章背景 |
| **浅色背景 (Light BG)** | `#FAF0F1` | 淡粉底，用于卡片/容器背景 |
| **进度条轨道 (Track)** | `#E8CED1` | 粉灰色，用于进度条未填充部分 |
| **进度条渐变 (Gradient)** | `#8B3A42 → #C27078` | 酒红渐变，用于进度条填充 |

## antd-mobile 组件主色覆盖

在使用 antd-mobile 的 `Button`、`Tabs`、`Tag` 等组件时，需在页面根元素上覆盖 CSS 变量：

```jsx
<div className="page-container" style={{ '--adm-color-primary': '#8B3A42' }}>
  {/* 页面内容 */}
</div>
```

## 色彩映射速查（替换旧蓝色用）

| 原蓝色 | 替换为 | 场景 |
|--------|--------|------|
| `#1677ff` | `#8B3A42` | 主色：按钮/链接/选中/箭头 |
| `#e6f4ff` | `#F5E6E8` | 标签浅蓝背景 → 浅粉背景 |
| `#1677ff` (标签文字) | `#C4737A` | 标签文字色（比主色浅） |
| `#f0f7ff` | `#FAF0F1` | 容器浅蓝背景 → 浅粉背景 |
| `#d4e8ff` | `#E8CED1` | 进度条轨道 |
| `#69b4ff` | `#C27078` | 渐变终点色 |
| `#0958d9` | `#8B3A42` | 深色文字标注 |
| `#f0f9ff` | `#FAF0F1` | 信息卡片背景 |
| `#91caff` | `#E8CED1` | 信息卡片边框 |
